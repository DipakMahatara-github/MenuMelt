# MenuMelt: QR-Based Restaurant Ordering System

MenuMelt is a full-stack solution designed to modernize the dining experience. Customers scan a table-specific QR code, browe the menu, and place orders directly from their phones. Restaurant staff and admins manage everything in real-time.

## Key Features
- **QR-Based Menu**: Instant access via unique table QR codes.
- **Real-Time Updates**: WebSockets ensure kitchen and staff see orders immediately.
- **Role-Based Access (RBAC)**: Distinct views for Admins, Kitchen, Waitstaff, and Customers.
- **Digital Payments**: Integrated with Khalti/Online providers.
- **Automated Notifications**: FCM-powered alerts for order status changes.
- **Subscription Model**: SaaS readiness for restaurant onboarding.

## Tech Stack
- **Frontend**: React.js, Tailwind CSS, Vite.
- **Backend**: Django, Django REST Framework, Django Channels.
- **Database**: PostgreSQL (Relational integrity for orders/menu).
- **Caching/PubSub**: Redis (required for WebSockets).
- **Auth**: JWT (Stateless, secure).

--- architecture.md ---

# System Architecture

## 1. High-Level Design
MenuMelt follows a decoupled **Client-Server** architecture:
- **Frontend (React)**: Handles UI/UX, client-side routing, and WebSocket listeners.
- **Backend (Django)**: REST API for data persistence and Channels for real-time events.
- **PostgreSQL**: Stores relational data (Users, Restaurants, Orders).
- **Redis**: Acts as the Channel Layer for multicasting order updates.

## 2. Data Flow
1. **Ordering**: Customer scans QR -> React fetches Menu -> Places Order -> REST API saves to DB -> WebSocket broadcasts to Kitchen Staff.
2. **Status Update**: Kitchen clicks "Ready" -> REST API updates DB -> WebSocket broadcasts to Customer & Waiter -> FCM sends push notification.

## 3. Real-Time (WebSockets)
We use **Django Channels** with a Redis backing. Rooms are partitioned by `restaurant_id`:
- `orders_restaurant_{id}`: Broadcasts new orders and status changes.

from django.contrib.auth.models import AbstractBaseUser, BaseUserManager, PermissionsMixin
from django.db import models

class UserManager(BaseUserManager):
    def create_user(self, email, password=None, **extra_fields):
        if not email: raise ValueError("Email is required")
        email = self.normalize_email(email)
        user = self.model(email=email, **extra_fields)
        user.set_password(password)
        user.save(using=self._db)
        return user

class User(AbstractBaseUser, PermissionsMixin):
    ROLE_CHOICES = (
        ("admin", "Admin"),
        ("staff", "Kitchen/Waitstaff"),
        ("customer", "Customer"),
    )
    email = models.EmailField(unique=True)
    full_name = models.CharField(max_length=255)
    role = models.CharField(max_length=20, choices=ROLE_CHOICES, default="customer")
    restaurant = models.ForeignKey('restaurants.Restaurant', on_delete=models.CASCADE, null=True, blank=True)
    is_active = models.BooleanField(default=True)
    is_staff = models.BooleanField(default=False)
    
    USERNAME_FIELD = "email"
    objects = UserManager()

--- backend/orders/consumers.py ---

import json
from channels.generic.websocket import AsyncWebsocketConsumer

class OrderConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        self.restaurant_id = self.scope['url_route']['kwargs']['restaurant_id']
        self.room_group_name = f'orders_restaurant_{self.restaurant_id}'

        await self.channel_layer.group_add(
            self.room_group_name,
            self.channel_name
        )
        await self.accept()

    async def disconnect(self, close_code):
        await self.channel_layer.group_discard(
            self.room_group_name,
            self.channel_name
        )

    async def order_update(self, event):
        # Called when a new order is placed or status modified
        await self.send(text_data=json.dumps(event['message']))

--- backend/tables/qr_utils.py ---

import qrcode
import jwt
from django.conf import settings

def generate_table_qr(restaurant_id, table_id, table_number):
    """
    Generates a secure QR code for a specific table.
    The QR encodes a URL with a signed JWT token.
    """
    payload = {
        "rest_id": restaurant_id,
        "table_id": table_id,
        "table_no": table_number,
    }
    token = jwt.encode(payload, settings.SECRET_KEY, algorithm="HS256")
    url = f"{settings.FRONTEND_URL}/menu?token={token}"
    
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(url)
    qr.make(fit=True)
    
    img = qr.make_image(fill_color="black", back_color="white")
    return img, token

--- frontend/src/api/api_service.js ---

import axios from 'axios';

const API_BASE_URL = 'http://localhost:8000/api';

const api = axios.create({
    baseURL: API_BASE_URL,
});

// Attach JWT token to every request
api.interceptors.request.use((config) => {
    const token = localStorage.getItem('access_token');
    if (token) {
        config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
});

export const OrderService = {
    fetchOrders: () => api.get('/orders/'),
    placeOrder: (orderData) => api.post('/orders/', orderData),
    updateStatus: (id, status) => api.patch(`/orders/${id}/`, { status }),
};

export default api;

--- frontend/src/hooks/useOrderSocket.js ---

import { useEffect, useState } from 'react';

export const useOrderSocket = (restaurantId) => {
    const [lastOrder, setLastOrder] = useState(null);

    useEffect(() => {
        if (!restaurantId) return;

        const socket = new WebSocket(`ws://localhost:8000/ws/orders/${restaurantId}/`);

        socket.onmessage = (event) => {
            const data = json.parse(event.data);
            setLastOrder(data);
        };

        return () => socket.close();
    }, [restaurantId]);

    return lastOrder;
};

# MenuMelt API Endpoints

### 1. Authentication
- `POST /api/token/`: Get JWT access/refresh tokens.
- `POST /api/token/refresh/`: Refresh access token.

### 2. Menu
- `GET /api/menu/`: Fetch categories and items for the restaurant.
- `POST /api/menu/items/`: Add new item (Admin only).

### 3. Orders
- `POST /api/orders/`: Place a new order.
- `GET /api/orders/`: List orders (Staff/Admin).
- `PATCH /api/orders/{id}/`: Update order status (Pending -> Preparing -> Ready).

### Example JSON: Place Order
```json
{
  "restaurant_id": 1,
  "table_id": 12,
  "items": [
    {"menu_item_id": 5, "quantity": 2},
    {"menu_item_id": 10, "quantity": 1}
  ]
}
```

# Setup & Installation Guide

### Backend Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Configure `.env` with DB credentials and Redis URL.
4. Run migrations: `python manage.py migrate`.
5. Start Redis: `docker run -p 6379:6379 -d redis`.
6. Start dev server: `python manage.py runserver`.

### Frontend Setup
1. Go to `frontend/` directory.
2. Install dependencies: `npm install`.
3. Start dev server: `npm run dev`.

### Features Testing
- Use **Postman** to test REST endpoints.
- Use **wscat** or Browser console to test WebSocket connections.
